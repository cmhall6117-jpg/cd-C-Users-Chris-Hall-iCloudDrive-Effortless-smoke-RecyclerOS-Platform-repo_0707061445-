# VS-001 Opportunity Discovery

Capability: CAP-101 Opportunity Discovery  
Workflow: WFL-001 Opportunity Discovery  
Events: EVT-001 Opportunity Discovered, EVT-002 Vehicle Evaluated, EVT-003 Procurement Intent Assigned  
Objects: Opportunity, Vehicle, Business Event  

## Acceptance Criteria
1. User can create an opportunity.
2. User can select procurement intent: resale, personal use, part-out, undecided.
3. User can distinguish source type: salvage yard, non-dealer auction, dealer auction, private seller, marketplace, manual.
4. System creates an Opportunity Discovered event.
5. Offline save is supported through sync queue design.
