- [ ] Create Python virtual environment.
- [ ] Install API requirements.
- [ ] Register routers.

- [ ] Resolve imports.
- [ ] Register routes.
- [ ] Run flutter analyze.
- [ ] Run flutter test.
- [ ] Launch on simulator/device.
