# VS-004 Pick List & Focus Point

Capabilities:
- CAP-401 Pick List Workflow
- CAP-402 Focus Point Workflow

Workflows:
- WFL-004 Pick List Management
- WFL-005 Focus Point Harvest

Acceptance Criteria:
1. Pick List displays no more than 10 vehicles per yard batch.
2. User can mark a vehicle Available or Unavailable.
3. Available starts Focus Point workflow.
4. Focus Point starts KPI timer.
5. Focus Point captures GPS location.
6. Save completes harvest session and records events.
7. Back cancels temporary KPI timer/session state.
